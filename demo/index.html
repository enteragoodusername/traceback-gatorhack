What the evidence establishes

Traceback searches an indexed source library. Shared imagery does not establish ownership, infringement, intent, or first publication. The controlled evaluation uses four licensed excerpts and scripted edits; it is not an internet-scale accuracy claim. Evidence checksums verify integrity, not authorship.

The recent core model is Qwen3-VL-Embedding-2B, released in January 2026. Retrieval ranks candidates; geometric and temporal checks verify shared visual content.
