# Prize strategy

This is a reasoned choice under a four-hour build constraint, not a prediction of a win. The strongest path is a coherent project with a convincing working demonstration, then multiple awards for which it genuinely qualifies.

## Priority

| Category | Published award | Traceback's case | Remaining condition |
| --- | --- | --- | --- |
| Overall | $2,000 first; $1,000 second; $500 third | A concrete media investigation problem, real recent model inference, transparent evidence, tested transformations, and a usable local application | Eligible team, timely submission, strong presentation |
| Vobile | Amount not announced | Video provenance and inspectable content matching are relevant to media technology; the stated judging challenge is the same as the main competition | Organizer judgment; sponsor fit is an inference, not a promise |
| Best Open Source Project | $25 gift card per team member | Public GitHub source, MIT application license, credited dependencies, reproducible installation, tests and evaluation | Public repository and eligible registered team |
| Best Use of Gemini | MLH swag | Implemented grounded evidence explanation | A real successful API demonstration; absent at build time |
| Best Use of Twinly API | Credits, subscriptions, internship interview opportunity | Implemented cloud evidence review and readiness check | Live credentials and sponsor confirmation that this cloud integration qualifies; the listing emphasizes macOS capabilities |

Award values and multiple-prize eligibility come from the [official prize page](https://ufgatorhack.com/prizes.html) and [Devpost overview](https://gatorhack2026.devpost.com/), checked October 24, 2026. The Twinly heading is labeled as cash on Devpost, but its detailed description specifies usage credits and subscriptions. Do not present those as cash winnings.

## Why this project

A broad “AI assistant for everything” is difficult to demonstrate convincingly in three minutes. Traceback has a visible before/after: an edited clip, a recovered source, and actual corresponding features. Its evidence export gives the technical work a clear user-facing purpose. The recent embedding model is used for both pixel retrieval and description-based archive search, rather than inserted only into a chat box.

The design supports the published judging dimensions:

- **Impact:** a narrowly defined archive/research workflow, with explicit unvalidated user and business hypotheses.
- **Technical execution:** actual CPU model inference, visual verification, temporal fitting, multi-source clips, bounded uploads, and independently testable evidence packets.
- **Design:** a legible source/query comparison, frame selection, source timestamps, attribution, and clear recorded/live modes.
- **Novelty:** the January 2026 multimodal embedding release is within the challenge window; transparent verification is the product distinction.
- **Presentation:** a short visual example, measured results, an honest no-match case, and clear limits.

## Do not weaken the entry

Do not claim internet-scale search, ownership determination, calibrated confidence, customers, revenue, or a production accuracy rate. Do not claim live sponsor usage based on a mocked test. Do not spend the main pitch explaining every optional integration. Lead with the strongest measured behavior.

Do not invent a roster. Software completeness does not waive the event's team, registration, department, or attendance requirements. The submission handoff identifies these separately from project readiness.
